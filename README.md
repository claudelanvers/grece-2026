# 🇬🇷 Grèce 2026

Cyclotourisme dans les îles Ioniennes et le Péloponnèse.

## Caractéristiques du voyage

* Distance totale : 910 km
* Dénivelé positif : 10 148 m
* 15 étapes cyclistes
* Octobre 2026

## Parcours

Igoumenitsa → Margariti → Préveza → Vassiliki → Fiskardo → Poros → Zacharo → Pylos → Kalamata → Oitylo → Gythio → Kosmas → Astros → Nauplie → Corinthe → Athènes → Diakopto → Patras

## Hébergements

14 hôtels réservés.

## Objectif du projet

Créer un site web interactif présentant :

* les traces GPX du voyage ;
* les cartes des étapes ;
* les hébergements ;
* les points d'intérêt touristiques ;
* la logistique du voyage ;

avec publication sur Netlify.
